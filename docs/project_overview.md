# 项目介绍

## 研究背景

水稻产量由穗数、每穗粒数、粒重及相关农艺性状共同影响。基因功能、自然变异和材料效应的研究分布在数据库、论文正文、图表与补充材料中。将这些信息按基因、事件、材料和实验条件连接，有助于比较不同研究中的结论，并发现适合进一步验证的育种线索。

RiceYield Prior 为这一过程提供可追溯的文献先验整理框架。项目围绕**来源—基因—分子事件—比较—性状端点**组织证据，并记录效应、原文定位和审阅状态。

## 研究问题与应用场景

项目适合育种研发、作物遗传学和生物信息团队用于：

- 梳理水稻产量相关基因及其自然变异、单倍型和功能证据；
- 建立包含材料、对照、环境、性状和文献定位的基因证据卡；
- 比较不同背景下的性状效应，记录正反结果和潜在代价；
- 为群体分析、候选变异筛选及后续实验设计提供文献依据；
- 让研究者和 Agent 围绕明确命题开展增量整理与复核。

项目覆盖产量构成、株型、抽穗期和其他相关农艺性状。TO 编号筛选提供一条候选发现支路，文献证据和已有功能基因也可以独立进入整理流程。

## 工作方式

1. **发现候选**：结合基因注释、文献检索和公开资源，建立候选与来源台账。
2. **定位原文**：核对文章身份及版本，按具体命题记录正文、图表和补充材料的位置。
3. **组织证据**：分别记录基因功能、工程扰动、自然等位、单倍型和关联证据。
4. **审阅与复核**：围绕材料、对照、端点、效应方向和研究条件开展人工审阅与独立复核。
5. **构建与使用**：固定输入和运行版本，生成 SQLite 与分类视图，按基因查询并交由下游研究使用。

## 分享版内容

仓库提供 Python 标准库脚本、TO 筛选规则、结构化输入模板、虚构示例和文献来源指南。功能包括候选筛选、Europe PMC 元数据检索与单篇 XML 获取、段落提取、本地模型候选整理、来源及事件关系检查、SQLite 构建和分页查询。

文献接口的实际接入方式见[公开文献来源](literature_sources.md#项目接口与导航清单)，完整字段说明见[输入契约](input_contract.md)，接手步骤见 [Agent 指南](agent_handoff.md)。
