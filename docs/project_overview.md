# 项目介绍

## 项目要解决什么问题

水稻产量由多个性状及其相互作用共同决定。相关基因和变异的研究分散在数据库、论文、图表和补充材料中；同名基因、不同材料或不同实验可能对应不同的事件和效应。直接汇总基因名或单个“增产”标签，难以追溯证据，也容易忽略背景条件和性状代价。

RiceYield Prior 将这些分散线索整理为**可追溯的文献先验**：从来源和候选基因出发，连接分子事件或单倍型、材料与对照、性状端点、观察结果、来源位置和审阅状态，使研究者能够判断某项结论适用于什么对象、什么条件，以及哪些问题仍待核实。

## 适用对象与使用场景

本项目适合育种研发、作物遗传学及生物信息团队共享研究方法和整理标准。可以用于梳理产量相关基因与自然变异、准备候选基因文献证据卡、识别争议及未决字段，或为后续群体分析和实验设计提供有出处的先验。

项目支持记录穗数、粒数、粒重等产量构成，以及与产量相关的株型、抽穗期和其他性状。示例中的三要素 TO 规则只是候选召回的一条支路；先验来源范围不限定为该规则命中的条目，也不以某个育种群体是否携带该变异作为文献收录条件。

## 工作方式

1. **发现来源与候选**：按可记录的检索范围查找基因注释、文献元数据和可获得的原文；保留未命中及未决记录。
2. **核验具体证据**：区分原始实验、引用说法与整理者推断，登记正文、图、表或补充材料中的定位。
3. **建立结构化关系**：分别保存来源、基因、分子事件、材料比较和端点；自然变异、工程扰动、关联代理及复合单倍型不自动混同。
4. **复核与发布**：检查身份关系、来源范围及记录完整性；实质性科学增量需要依据原始证据独立复核，再固定输入、代码和产物版本。
5. **供下游使用**：按基因查询证据和未决问题；下游项目另行核验材料身份、分型来源、比较设计与结果适用范围。

## 当前分享版包含什么

仓库提供 Python 标准库脚本、TO 规则、结构化录入模板、示例与使用说明。脚本可进行候选筛选、Europe PMC 元数据检索、来源整理、证据关系校验、SQLite 构建、分层导出、基因查询和多来源链接导航。文献发现入口汇总于[公开文献与资源入口](literature_sources.md)。

这里的示例基因、变异、论文和效应均为虚构，方便理解字段和运行命令；仓库未发布内部科研数据库或实际材料数据。本分享版是可移植的简化实现，不替代内部生产数据库、来源资产审阅、独立复核回执或科学判断。

## 如何理解结果

先验是提出和组织问题的依据。一个关联结果不自动等于因果事件；文献中的基因功能不自动证明当前材料携带某个等位；单性状有利也不自动意味着田间总产量提升。项目保留负结果、背景差异、潜在代价和未决状态，供后续验证时使用。
